## The dashboard tabs

| Tab | What it is for |
|---|---|
| [Vehicles](vehicles.md) | Household overview, live status, totals |
| [Drives](drives.md) | Calendar, heat maps, day and drive maps, charts, stats |
| [Fav Routes](fav-routes.md) | Repeated routes ranked fastest to slowest |
| [Destinations](destinations.md) | Named places and zones |
