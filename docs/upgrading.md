# Upgrading from 1.5.x to 2.0

2.0 is a large release: a new dashboard, a places and routes layer, charging and efficiency pages, and a SQLite analytics store. Most of the upgrade is automatic.

## Steps

1. Update through HACS (or copy the new `custom_components/rivian` folder) and **restart Home Assistant**.
2. A fresh install creates the dashboard automatically, but if you already have a Rivian dashboard from an earlier version it is left as is. Run **Create Rivian dashboard** (`rivian.create_efficiency_dashboard`) again to regenerate the dashboard with the new tabs: Vehicles, Drives, Fav Routes, Destinations, Charging, Efficiency. Dashboards generated by earlier versions are repaired in place.
3. Hard-refresh your browser (see [FAQ](faq.md#the-dashboard-looks-broken-or-shows-old-cards-after-upgrading)).

## What happens automatically

- **Database migration.** The analytics database (`.storage/rivian_analytics.db`) is upgraded to schema version 14 on first start. Your existing drives, routes and charging sessions are kept. Take a Home Assistant backup first if you want a safety net.
- **Places and routes** are built from your existing drives in the background, so Destinations and Fav Routes fill in shortly after the restart.
- **Weather** for stored drives is filled once in the background, which powers the new Efficiency page.
- **Home and AC charging** is recorded from now on. Sessions before the upgrade are not in the history unless you run `rivian.import_charging_history`.
- Long-term statistics (`rivian:*`) continue unchanged.

## What changed

- The **Plotly-based efficiency and charging tabs are replaced** by the new custom cards. You no longer need to maintain Plotly charts.
- The **Dashboard vehicle select entity is deprecated**. Vehicle choice is now the [vehicle bar](vehicle-bar.md), remembered per user. The entity still exists but does nothing useful; you can disable or ignore it.
- **Places and routes belong to no vehicle.** They are shared across the household; visits are counted per vehicle.
- A **Vehicles tab** replaces the old Overview.

## Old dashboards

Dashboards created by earlier versions (for example one named "Efficiency") are no longer updated. Once you are happy with the new "Rivian" dashboard, delete the old ones in **Settings > Dashboards**. Deleting a dashboard does not delete any data.

## Rolling back

Downgrading the integration after the database migrated is not supported. Restore a Home Assistant backup taken before the upgrade if you need to go back. Older `rivian_drives_<VIN>.json` files from before the SQLite store are left untouched on disk.
