# Upgrading from 1.5.x to 2.0

2.0 is a large release: a new dashboard, a places and routes layer, charging and efficiency pages, and a SQLite analytics store. Most of the upgrade is automatic.

## Steps

1. Update through HACS (or copy the new `custom_components/rivian` folder) and **restart Home Assistant**.
2. Turn on **Drive analytics** in the integration's options (**Configure**). It is off by default, and nothing below happens until it is on. Only administrators can view the analytics unless you also turn on **Let non-admin users view drive analytics**.
3. A fresh install creates the dashboard automatically, but if you already have a Rivian dashboard from an earlier version it is left as is. Run **Create Rivian dashboard** (`rivian.create_efficiency_dashboard`) again to regenerate the dashboard with the new tabs: Vehicles, Drives, Fav Routes, Destinations, Charging, Efficiency. Dashboards generated by earlier versions are repaired in place.
4. Hard-refresh your browser (see [FAQ](faq.md#the-dashboard-looks-broken-or-shows-old-cards-after-upgrading)).

## What happens once drive analytics is on

- **Analytics database.** `.storage/rivian_analytics.db` is created on the Home Assistant host. There is nothing to migrate from 1.5.x. Home Assistant backups include it.
- **Places and routes** are built from your drives in the background, seeded from your Home Assistant zones.
- **Weather** for stored drives is filled once in the background when you turn on **Weather for drives and charging** (off by default), which powers the Efficiency page's conditions.
- **Charging** (fast and home/AC) is recorded from now on. Earlier sessions are not in the history unless you run `rivian.import_charging_history`, or `rivian.backfill_drive_history` while the recorder still has them.
- Hourly totals go to Home Assistant long-term statistics (`rivian:*`), which Home Assistant never purges.

## What changed

- **Drive analytics are opt-in** and admin-only by default; every analytics action is admin-only.
- Vehicle choice is the [vehicle bar](vehicle-bar.md), remembered per user.
- **Earlier test builds only:** the Plotly charts, the bundled Plotly Graph Card and Mushroom cards, and the "Dashboard vehicle" select are gone. Their Lovelace resources and the select are removed automatically; install Plotly Graph Card or Mushroom yourself (for example from HACS) if your own dashboards use them.
- **Places and routes belong to no vehicle.** They are shared across the household; visits are counted per vehicle.
- A **Vehicles tab** replaces the old Overview.

## Old dashboards

Dashboards created by earlier versions (for example one named "Efficiency") are no longer updated. Once you are happy with the new "Rivian" dashboard, delete the old ones in **Settings > Dashboards**. Deleting a dashboard does not delete any data.

## Rolling back

Going back to 1.5.x works: it ignores `.storage/rivian_analytics.db`, which stays on disk. Delete the file if you will not return to 2.0, or remove the integration, which deletes it.
